Executive conclusion

This report separates native no-ML evidence from learned models. It asks whether short-read differential events are independently supported by Bambu-derived long-read event paths, then measures signed ΔPSI agreement. Machine learning is evaluated only out of sample. Cross-validation estimates uncertainty; it does not create extra accuracy.

Scope: internal five-cell-line validation only. A new laboratory/protocol dataset and orthogonal IGV/RT-PCR confirmation were deliberately excluded at this stage, as requested.

1. Biological universe and audit

rMATS event geometry defines five explicit path types. Bambu transcript counts are summed within each event path for every biological replicate. Long-read event PSI is path A/(path A+path B). An event is quantitatively evaluable only when both conditions have ≥2 replicates with ≥10 path reads. The primary binary endpoint is the established Bambu + DEXSeq differential label projected onto the event path. The separate strict event positive column additionally requires event |ΔPSI|≥0.10 and BH-adjusted Welch FDR≤0.05; only 19 events meet that deliberately conservative definition.

5. Fair common universe

Direct comparisons are restricted to long-read-evaluable rows where the relevant method has a value. Consensus comparisons require multiple methods. This avoids rewarding a method for testing an easier or larger universe. Native and common-universe N values are printed in every row.

5. PSI-derived differential route

The prior SpliceScore PSI predictions are differenced as ΔPSI = predicted PSI(A) − predicted PSI(B), then projected into the same event orientation. This tests whether a strong single-condition PSI model remains useful after differencing. Its performance appears as PSI-derived in the no-ML tables and as the starting term of the hybrid residual model.

6. Held-out machine learning

Genes are assigned deterministically to 80% training and 20% untouched validation, so events from the same gene cannot leak between partitions. Models use caller ΔPSI, significance, depth, availability and event class. The long-read target is never used as an input.

9. What this does—and does not—establish

A high score means “similar to short-read events that were reproducibly supported by long-read path usage in this five-cell-line dataset.” It is not a p-value, not an FDR, and not proof of biological truth. Long reads have their own depth and isoform-assignment errors. A publication claim should emphasize calibrated support and generalization across held-out genes/pairs, while reserving external-protocol and RT-PCR/IGV validation for later phases.
